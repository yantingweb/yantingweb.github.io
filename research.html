Unitree G1 · 运动跟踪与评估仿真实验

训练 G1 拳击动作，验证仿真结果

我的角色：动作处理、奖励迭代与评估扩展

参考动作PPO 跟踪训练固定靶评估靶位扫描
要解决的问题
基于现有运动跟踪框架迁移拳击动作，并评估接触力读数是否能反映有效的仿真碰撞。
我做了什么
筛选、裁切与桥接参考动作；迭代手臂跟踪及拳速奖励；扩展固定靶评估与三维靶位扫描，分析靶位和接触伪影对读数的影响。
结果与证据
项目记录的标定仿真固定靶峰值约 303 N；同时记录了靶位偏差与随机化对结果的敏感性。
技术栈
Python / MuJoCo / mujoco-warp / RSL-RL PPO / ONNX
实验范围与贡献边界

303 N 是特定条件下的仿真接触力峰值，不代表真机力度或多次实验均值。训练基于上游运动跟踪与 PPO 框架。

Aero Hand · 单目视觉遥操作实机链路

让灵巧手跟随人手运动

我的角色：个人复现与实机集成

摄像头手部关键点动作重定向串口 → 灵巧手
要解决的问题
将摄像头捕获的人手动作映射到欠驱动灵巧手，让视觉、重定向和硬件通信形成闭环。
我做了什么
适配 Windows 运行环境与串口 I/O，排查探测超时、读帧不完整和残留帧问题；编写数值对照与尺度标定工具。
结果与证据
完成 Windows 单进程实机遥操作链路，公开仓库提供通信排错、标定与验证文档。
技术栈
Python / OpenCV / MediaPipe / DexPilot / MuJoCo
实验范围与贡献边界

重定向采用上游 DexPilot；个人贡献集中在环境适配、通信、标定与验证。
