CASE 01Research-oriented engineering · 2026

G1 boxing: motion tracking & simulation evaluation

Background
Adapt human motion to a Unitree G1 humanoid using an existing motion-tracking framework, and evaluate simulated contact forces.
My contribution
Selected and processed reference motions, iterated reward terms, and extended the evaluation tooling with a fixed-target mode and target-position sweeps. Built on upstream motion-tracking and PPO implementations.
Technical stack
Python · MuJoCo · mujoco-warp · RSL-RL / PPO · ONNX
Evidence & results
The project README reports a peak of approximately 303 N in a calibrated fixed-target simulation. This is a simulator contact-force reading, sensitive to target placement and domain randomization; it is not a hardware measurement or a repeated-trial mean.

CASE 02Open-source reproduction & hardware integration · 2026

Aero Hand: monocular vision teleoperation

Background
Reproduce the upstream Aero Hand teleoperation pipeline and connect monocular hand tracking to an underactuated robotic hand.
My contribution
Adapted the runtime and serial I/O, built comparison and calibration tools, and debugged communication failures. Retargeting uses the upstream DexPilot implementation; I do not claim a new retargeting algorithm.
Technical stack
Python · OpenCV · MediaPipe · dex_retargeting / DexPilot · MuJoCo · serial I/O
Evidence & results
Hardware operation and calibration are documented in the public repository. The working hardware path uses a Windows single-process loop; ROS 2 simulation work is separate and does not establish a completed ROS 2 hardware bridge.
