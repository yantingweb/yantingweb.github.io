Unitree G1 · 运动跟踪与评估仿真实验

训练 G1 拳击动作，验证仿真结果

我的角色：动作处理、奖励迭代与评估扩展

参考动作PPO 跟踪训练固定靶评估靶位扫描
要解决的问题
基于现有运动跟踪框架迁移拳击动作，并评估接触力读数是否能反映有效的仿真碰撞。
我做了什么
筛选、裁切与桥接参考动作；迭代手臂跟踪及拳速奖励；扩展固定靶评估与三维靶位扫描，分析靶位和接触伪影对读数的影响。
结果与证据
项目记录的标定仿真固定靶峰值约 303 N；同时记录了靶位偏差与随机化对结果的敏感性。
技术栈
Python / MuJoCo / mujoco-warp / RSL-RL PPO / ONNX
实验范围与贡献边界

303 N 是特定条件下的仿真接触力峰值，不代表真机力度或多次实验均值。训练基于上游运动跟踪与 PPO 框架。
